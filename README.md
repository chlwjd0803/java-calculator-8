# 문자열 덧셈 계산기

## 🚀 기능 목록
- [ ] 쉼표(,), 콜론(:), 사용자 정의 구분자를 구분자로 가지는 문자열을 입력받아 각 숫자의 합을 반환한다.
    - 예: "1,2:3" → 6
- [ ] 숫자 이외의 값이 입력되거나, 구분자가 연속으로 사용되는 등 유효하지 않은 입력 값에 대해 `IllegalArgumentException` 예외를 발생시킨다.
- [ ] 커스텀 구분자를 지정할 수 있다.
    - 커스텀 구분자는 "//"와 "\n" 사이의 문자를 사용한다.
    - 예: "//;\n1;2;3" → 6


## ✍️ 커밋 메시지 컨벤션

- `feat`: 새로운 기능 추가
- `fix`: 버그 수정
- `ref`: 코드 리팩토링 (기능 변경 없이 코드 구조 개선)
- `docs`: 문서 수정 (README.md 등)
- `test`: 테스트 코드 추가 또는 수정
